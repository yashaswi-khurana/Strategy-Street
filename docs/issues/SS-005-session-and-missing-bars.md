# SS-005 — Market Session Filter & Missing-Bar Policy

| | |
| --- | --- |
| Milestone | 0 — Foundations |
| Depends on | SS-002 |
| Blocks | SS-009, SS-011, SS-019, SS-026 |
| Size | ~1.5 days |
| Stack | Go (+1:1 mirror in Python) |

## Goal

One authoritative answer to "is this timestamp inside a valid trading session?" and "what do I do with a
minute that has no trades?" — used identically by the streamer, backfiller, backtester and paper engine.

## Scope

**In scope**
- Go package `internal/marketcal`:
  - `Session(day time.Time) (open, close time.Time, ok bool)` — holiday- and special-session-aware.
  - `IsOpen(t time.Time) bool`, `TradingDays(from, to) []time.Time`.
  - `NextBarClose(now, tf) time.Time` — deterministic bar-close instant (used by SS-026).
  - `BarsPerSession(tf)` (375 for 1m, 22500 for 1s, 1 for 1d).
- Bar-gap policy helpers: `MissingBars(expected, actual)` and `FillPolicy` enum:
  `CarryForward` (repeat last close, volume 0, flag `is_filled`) — default, and `Skip` (no row).
- A `time_model` note inside each candle row is **not** added; instead store `is_filled BOOLEAN` via a
  migration add-on to keep the schema honest (add column now, default false).
- Python mirror `engine/marketcal.py` with identical semantics (property-tested against Go fixtures).

**Out of scope**
- Detecting gaps in Upstox data (SS-009), aggregating ticks (SS-011).
- Pre-market/post-market inclusion (explicitly unsupported; documented).

## Small architecture

```go
type Calendar struct { /* holidays, sessions, loc *time.Location */ }

func (c *Calendar) Session(t time.Time) (open, close time.Time, ok bool) // IST, from DB
func (c *Calendar) IsOpen(t time.Time) bool                            // open <= t < close
func (c *Calendar) TradingDays(from, to time.Time) []time.Time          // IST dates
func (c *Calendar) NextBarClose(now time.Time, tf candles.Timeframe) (time.Time, bool)
```

* Everything converts to `Asia/Kolkata` at the boundary; internal comparisons use absolute time.
* Session boundaries are half-open `[09:15, 15:30)`. A tick at exactly 15:30:00 IST belongs to **no** bar
  (never create a phantom last-second bar).
* `NextBarClose` for 1m with `now = 09:16:12` returns `09:17:00`, and returns `(zero,false)` after close.
  It must never depend on wall-clock seconds — this is what makes paper trading deterministic.
* Fill policy is applied at **read time** by a decorator `filledRange(...)` that takes a slice of candles plus
  the calendar and returns a gap-free series with `is_filled=true`, `volume=0`. Backtests and charts both call
  it, so they cannot disagree.
* Filled bars must never be *written* to the DB (no phantom volume in storage).

## Acceptance criteria

1. `IsOpen(2026-03-14T09:14:59+05:30)` false, `09:15:00` true, `15:29:59` true, `15:30:00` false.
2. `Session()` returns `ok=false` for a holiday and for a weekend (from DB + weekday rule).
3. For a 1m series missing 11:00–11:04, the `CarryForward` decorator returns 5 extra bars with `volume=0`,
   `is_filled=true`, and `close` equal to the 10:59 close; highs/lows equal that close.
4. `BarsPerSession(1m) == 375` and `TradingDays(2026-01-01, 2026-03-31)` excludes every seeded holiday.
5. Go and Python produce identical output for all fixtures in `engine/testdata/sessions.json`.

## Test plan
