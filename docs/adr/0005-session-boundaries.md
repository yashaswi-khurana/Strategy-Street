# ADR 0005: Market Session Boundaries, Deterministic Bar-Close & Read-Time Missing-Bar Policy

## Status
Accepted

## Context
Across Strategy Street, distinct subsystems (live tick streamer, historical REST backfiller, vectorized Python backtester, and Go paper execution engine) must answer two critical questions identically:
1. **Session Boundary**: "Is timestamp $T$ inside a valid trading session, and when does the current bar close deterministically?"
2. **Missing-Bar Policy**: "What happens when an illiquid stock or quiet minute has zero market trades?"

### Problems Addressed
1. **Phantom Last-Second Bars**: In traditional market feeds, ticks stamped at exactly `15:30:00` IST often create a phantom 376th minute bar (`15:30:00 - 15:31:00`) or contaminate daily rollups.
2. **Wall-Clock Non-Determinism**: If paper trading or strategy evaluation determines bar closing by querying `time.Now()` or wall-clock seconds, historical replaying and live execution diverge, breaking determinism.
3. **Database Write-Amplification & Phantom Volume**: Persisting forward-filled zero-volume bars into TimescaleDB amplifies hypertable storage, inflates compression overhead, and creates fake volume records.
4. **Cross-Language Divergence**: If the Go API and the Python strategy engine compute session boundaries or gap filling with even a single second or sub-penny difference, backtest signals and live orders disagree.

## Decisions

### 1. Half-Open Session Interval Semantics
All market session boundaries are strictly evaluated as half-open intervals:
```
[open_time, close_time)
```
- In regular NSE equity sessions: `[09:15:00, 15:30:00)` IST.
- A tick at `09:14:59.999` is outside the session (`IsOpen == false`).
- A tick at `09:15:00.000` is inside the first bar (`IsOpen == true`).
- A tick at `15:29:59.999` is inside the final bar (`IsOpen == true`).
- A tick at `15:30:00.000` belongs to NO bar (`IsOpen == false`).

### 2. Pure, Deterministic Bar-Close Calculation (`NextBarClose`)
`NextBarClose(now, tf)` returns the deterministic bar-close instant for timestamp `now` and timeframe `tf`:
- Pure function of the provided timestamp; never inspects wall-clock seconds or system time.
- Returns `ok = false` if `now` is outside active session hours (`now < open` or `now >= close`).
- For `1m` with `now = 09:16:12`, returns `09:17:00 IST`.
- For `1m` with `now = 15:29:15`, returns `15:30:00 IST`.
- At or after `15:30:00`, returns `(zero, false)`.
- For `1d`, returns session close (`15:30:00 IST`).

### 3. Read-Time Missing-Bar Decoration with `is_filled`
Missing bars (intervals with zero trades) are handled via a read-time decorator `FilledRange`:
- **CarryForward (Default)**: For missing minutes within active session hours, synthesizes bars where `open = close = high = low = previous.close`, `volume = 0`, `oi = previous.oi`, and `is_filled = true`.
- **Skip**: Leaves the series as-is, returning only actual trade bars.
- **Strict Read-Time Only**: Synthesized filled bars are never written to TimescaleDB. `ValidateBar()` strictly rejects any candle with `is_filled = true`.
- **Schema Honest**: Migration `0005_is_filled.up.sql` adds `is_filled BOOLEAN NOT NULL DEFAULT FALSE` to `candles_1s` and `candles_1m`. Continuous aggregates pass it through via `bool_and(is_filled) AS is_filled`.

### 4. Cross-Language 1:1 Mirror
- Go implementation: `internal/marketcal` (`Calendar`, `FilledRange`, `NextBarClose`).
- Python mirror: `engine/marketcal.py` (`Calendar`, `filled_range`, `next_bar_close`).
- Verified via shared test fixture `engine/testdata/sessions.json` generated by Go and verified by pytest.

## Consequences

### Positive
- Zero divergence between Go live trading and Python backtesting.
- Zero storage inflation from forward-filling zero-volume bars in the database.
- Deterministic paper trading playback and backtesting.
- Clean separation between storage truth (unfilled raw trades) and consumer needs (continuous time series).

### Negative / Trade-offs
- Consumers requesting continuous time series must invoke `FilledRange` or `filled_range` at query/read time.
